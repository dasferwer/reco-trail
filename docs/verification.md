# Проверки RecoTrail

Проверено 11 сентября 2026 года на Docker Desktop, ARM64.

| Проверка | Результат |
|---|---|
| PostgreSQL integration tests и модель | **24 passed in 5.62s** |
| Ruff lint / format / uv.lock | Пройдены |
| API и база | Healthy |
| Повтор seed | Два успешных запуска, история сохраняется |
| Runtime | UID 999; pytest, Ruff и scikit-learn отсутствуют |
| OpenAPI | Снимок совпадает с живым API |

Интеграционные тесты проверяют 12 конкурентных повторов одного запроса,
10 разных событий одного пользователя, позднее событие, одинаковые timestamps,
приватность, If-Match, смену модели и каталога, новый фильм без факторов,
пагинацию и атомарный откат при ошибке PostgreSQL. Метрики четырёх алгоритмов
пересчитываются из исходного CSV и совпадают с сохранённым отчётом.

Через HTTP пройден путь нового пользователя: популярность → выбор жанров → лайк
→ персональная выдача. Проверены повтор ключа, позднее событие, попадание в кэш
и обновление результата после скрытия фильма администратором.

API завершён через SIGKILL после подтверждённого события. После перезапуска
повтор с тем же ключом оставил одно событие, версия профиля и рекомендации
совпали с результатом до остановки.

Подробности: [verification.json](verification.json),
[smoke](smoke-verification.json), [recovery](recovery-verification.json).
GitHub Actions повторяет проверки; [актуальный статус](https://github.com/dasferwer/reco-trail/actions). Нагрузочное испытание
и потеря диска PostgreSQL не проводились.
